# Bagrut Vocabulary Practice — מבחן אוצר מילים

## Deploy to Netlify
1. Push to GitHub
2. app.netlify.com → Add new site → Import from GitHub
3. Build command: `npm run build` | Publish directory: `dist`
4. Deploy

## Deploy to Vercel
1. Push to GitHub
2. vercel.com → New Project → Import → Deploy

## Run locally
```bash
npm install
npm run dev
```

## First launch
Click **"השלם תרגומים באמצעות AI"** to auto-fill all missing Hebrew translations
via the Claude API. Results are saved to localStorage permanently.
